# Восемь уровней Every: рабочая карта

Первоисточник: https://every.to/guides/the-eight-levels-of-ai-adoption

Используйте как качественную модель, не как лицензированный/официальный тест Every. Смысл уровней следует перепроверять по первоисточнику при публикации новой версии.

| № | Уровень | Рабочий признак | Чего недостаточно для подтверждения |
|---|---|---|---|
| 1 | Chatbot | Запросы и ответы в чате | Просто наличие подписки |
| 2 | Copilot | Совместная работа внутри документов/приложений | Вставка фрагмента текста в чат сама по себе |
| 3 | Agent | Многошаговое выполнение с промежуточными согласованиями | Только план шагов |
| 4 | Autopilot | Завершение ограниченной задачи без промежуточного участия | Черновой совет без действий |
| 5 | Workflows | Воспроизводимый процесс с проверяемым качеством | Серия несвязанных промптов |
| 6 | Assistant | Проактивная работа по полезному контексту | Обычный таймер или дайджест без контекстной инициативы |
| 7 | Multi-agent | Несколько агентов выполняют согласованные роли, пользователь координирует | Несколько разных чатов без координации |
| 8 | Orchestrator | Агент-руководитель координирует других агентов | Один агент с длинным промптом |

Не нужно обязательно проходить уровни линейно: у человека могут существовать элементы высоких уровней при низкой зрелости других процессов. Не путайте технологическую сложность и эффективность.
