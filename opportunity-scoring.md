# Отбор возможностей для автоматизации

Для каждого кандидата оцените **качественно**: польза (низкая/средняя/высокая), повторяемость, техническая осуществимость, проверяемость результата, риск утечки/ошибки, цена настройки и поддержки.

Можно использовать вспомогательный рейтинг 1–5 по каждому параметру, но обязательно указывать, что это **эвристика автора скилла, не методология Every и не расчёт ROI**. При нехватке данных не рисуйте точные экономические эффекты.

При равной пользе предпочитайте:
1. Чтение и подготовку черновиков вместо публикации и изменения исходников.
2. Задачи с ясным критерием успешности.
3. Обратимые, дешёвые в отладке действия.
4. Возможности в уже используемых инструментах вместо новых подписок.

**Для каждого кандидата:**

| Поле | Что записать |
|---|---|
| Сценарий | Наблюдаемая работа пользователя |
| Фактура | Ссылка/пример/самоотчёт и уверенность |
| Текущий процесс | Действия человека и ИИ |
| Целевой процесс | Что автономизируется |
| Вход/выход | Конкретные форматы |
| Требуемые доступы | Минимально достаточные |
| Риски | Ошибки, приватность, стоимость, репутация |
| Контроль | Когда нужна проверка человека |
| Метрика | Фактическое время, качество, ошибки, успешные запуски |
| Пилот | Маленький, безопасный, обратимый |
| Откат | Как отключить и восстановить исходное состояние |
